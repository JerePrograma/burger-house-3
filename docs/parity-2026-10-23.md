# Homologación funcional — 23/10/2026

Alcance autorizado: mismas funcionalidades y correcciones en Tu Comida y Burger House, conservando nombres, credenciales, datos y alojamiento de cada proyecto; guardar en Git y publicar.

## Funcionalidad compartida verificada

- Catálogo, fotos, variantes, ingredientes, adicionales, disponibilidad, carrito y pedido por WhatsApp.
- Editor móvil con borrador, importación/exportación, publicación autenticada y control de revisión para evitar pérdida de ediciones.
- Gestión de pedidos, inventario, caja, cobros, devoluciones, turnos, compromisos y conciliación.
- Rutas agrupadas con Routes en catálogo y gestión; cobertura del arranque con React e Ionic reales en modos web, gestión y nativo.
- Formulario de acceso con URL pública explícita, permisos/orígenes validados y sesiones separadas de gestión/editor.
- Mismas versiones y lockfile equivalente, salvo nombre del paquete. Cuarenta archivos comunes se verifican mediante shared-code.json y npm run parity:check.

## Configuración propia y preservación

VPS Hostinger con Node.js/SQLite y Docker Compose; Cloudflare conserva el proxy y los enlaces heredados.

No se copian catálogos, pedidos, clientes, caja, claves, fotos ni el seed de un comercio al otro. Las direcciones, teléfonos, marcas, identificadores de aplicación y almacenamiento del navegador permanecen independientes. Las migraciones históricas no se modifican. Se recupera el catálogo vigente de cada proyecto antes de compilar.

La verificación remota previa aceptó las sesiones propias y rechazó tanto las del otro comercio como el intercambio entre editor y gestión. La línea base privada registra huellas de catálogo, estado operativo y archivos locales de autenticación; se vuelve a comparar después de publicar. El chequeo no escribe datos operativos ni muestra credenciales.
